XbUme 调试工具箱 —— 测试人员使用说明（Windows）
===============================================

一、安装
  1. 双击 XbUme-<版本>-setup.exe
  2. 一路「下一步」即可（不需要管理员权限，装在当前用户目录）
  3. 建议保留「创建桌面快捷方式」和「立即启动 XbUme」

  没有安装包时，直接把整个程序目录拷到电脑上，双击里面的 xbume-ide.exe
  也能用（免安装）。

二、启动
  双击桌面 / 开始菜单里的 XbUme，会自动打开浏览器页面（127.0.0.1:46129）。
  - 启动时会出现一个命令行窗口，那是后台服务，最小化不要关
  - 浏览器没弹出来就手动访问：http://127.0.0.1:46129
  - 46129 被占用时会自动顺延（46130、46131…），启动窗口里会打印实际地址

  退出：页面右上角「服务」→ 停止全部；或卸载程序（卸载会自动收掉进程）。

三、连接被测设备
  1. 用 USB 线连电脑，被测包必须是开发给你的「调试包」
     （构建时开了 xbume agent 开关的版本；应用市场里的正式版连不上）
  2. Android：设置 → 开发者选项 → 打开「USB 调试」，手机上点「允许」
     鸿蒙：设置 → 系统和更新 → 开发人员选项 → 打开「USB 调试」
     iOS：手机上点「信任此电脑」，输入锁屏密码
  3. 打开被测 App，等 1～2 秒，页面左侧会话列表出现该 App 即可点选

  连接工具（adb / hdc / iproxy）已经打包在程序目录的 tools 下，不用另外装。
  Windows 上连 iPhone 需要电脑已装 iTunes（提供 Apple 设备驱动），
  否则 iproxy 无法建立端口转发，iOS 会话不会出现。

四、能做什么（与命令安装版完全一致）
  - 日志：实时日志、按级别/关键字过滤、复制导出
  - 网络：请求列表、详情、耗时
  - 异常：崩溃与未捕获异常
  - 时间轴：日志 / 网络 / 异常按时间合并查看
  - 界面：截图、点按 / 输入 / 滑动、当前页面路由
  - 数据：沙盒文件浏览与下载、本地数据库只读查询、本地存储键值
  - 性能：CPU / 内存采样
  - 调试（仅 debug 包）：断点、单步、热重载、热重启、表达式求值、路由栈
  - 全局快捷键：调试页可给热重载 / 热重启绑系统级组合键
  - MCP：给 Claude / Cursor 等 AI 客户端接入，页面「MCP」页可一键复制配置
  - AI：自然语言驱动，页面「AI」页配置模型后可用

  依赖 Flutter 调试通道的能力（断点、单步、热重载、表达式求值、路由栈详情）
  在直连模式下会自动置灰，这是正常的：测试包不带调试通道。

五、常见问题
  - 会话列表是空的
      · 确认被测包是「调试包」（不是应用市场里的正式版）
      · 确认手机上已允许 USB 调试 / 信任电脑
      · 拔插一次数据线，或重启被测 App
      · 鸿蒙设备用 HiSuite 或 DevEco 授权过 USB 调试后 hdc 才能连上
  - 浏览器打不开页面
      · 确认启动窗口（cmd 黑窗口）还在运行
      · 再双击一次 XbUme，会自动打开页面
  - 杀毒软件报警
      · 把安装目录加入白名单（程序未做商业签名）
  - 端口被占用
      · 关掉占用 46129 的程序，或看启动窗口打印的实际端口
  - 想让服务彻底停止
      · 页面右上角「服务」→ 停止 GUI 与守护进程
      · 或任务管理器结束 xbume-gui.exe / xbume-ide.exe

六、反馈问题时请附上
  - 设备型号 + 系统版本
  - 被测包版本号
  - 应用版本：页面右上角关于里可以看到
  - 出问题时的截图（页面 + 手机界面）
