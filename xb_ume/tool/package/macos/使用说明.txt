XbUme 调试工具箱 —— 测试人员使用说明
=====================================

一、安装
  1. 双击打开 XbUme-<版本>.dmg
  2. 如果提示「无法验证开发者」：先双击同目录的「首次打开.command」（会解除隔离），
     再把 XbUme.app 拖到左侧 Applications（应用程序）里
  3. 从「应用程序」或启动台打开 XbUme

  打包机没有 Apple 开发者证书，所以第一次打开会被系统拦；按第 2 步处理一次即可。
  已装过旧版本的话，直接把新的 XbUme.app 拖进 Applications 覆盖。

二、启动
  双击 XbUme.app 后会自动打开浏览器页面（地址 127.0.0.1:46129）。
  如果浏览器没弹出来，手动访问：http://127.0.0.1:46129

  双击 app 只是「把服务叫起来」，服务在后台常驻；
  要彻底退出：页面右上角「服务」→ 停止全部，或直接关闭电脑重启。

三、连接被测设备（不需要装任何开发工具）
  1. 用 USB 线连电脑，被测包必须是开发给你的「调试包」
     （构建时开了 xbume agent 开关的版本；普通线上包连不上）
  2. Android：设置 → 开发者选项 → 打开「USB 调试」，手机上点「允许」
     鸿蒙：设置 → 系统和更新 → 开发人员选项 → 打开「USB 调试」
     iOS：手机上点「信任此电脑」，输入锁屏密码
  3. 打开被测 App，等 1～2 秒，页面左侧会话列表出现该 App 即可点选

  连接工具（adb / hdc / iproxy）已经打包在应用里，不用另外安装。

四、能做什么（与命令安装版完全一致）
  - 日志：实时日志、按级别/关键字过滤、复制导出
  - 网络：请求列表、详情、耗时
  - 异常：崩溃与未捕获异常
  - 时间轴：日志 / 网络 / 异常按时间合并查看
  - 界面：截图、点按 / 输入 / 滑动、当前页面路由
  - 数据：沙盒文件浏览与下载、本地数据库只读查询、本地存储键值
  - 性能：CPU / 内存采样
  - 调试（仅 debug 包）：断点、单步、热重载、热重启、表达式求值、路由栈
  - 全局快捷键：调试页可给热重载 / 热重启绑系统级组合键
  - MCP：给 Claude / Cursor 等 AI 客户端接入，页面「MCP」页可一键复制配置
  - AI：自然语言驱动，页面「AI」页配置模型后可用

  依赖 Flutter 调试通道的能力（断点、单步、热重载、表达式求值、路由栈详情）
  在直连模式下会自动置灰，这是正常的：测试包不带调试通道。

五、常见问题
  - 会话列表是空的
      · 确认被测包是「调试包」（不是应用市场里的正式版）
      · 确认手机上已允许 USB 调试 / 信任电脑
      · 拔插一次数据线，或重启被测 App
  - 浏览器打不开页面
      · 先确认 XbUme.app 还在运行（Dock 里可能已经退出，服务仍在）
      · 再双击一次 XbUme.app，会自动打开页面
  - 想让服务彻底停止
      · 页面右上角「服务」→ 停止 GUI 与守护进程
  - 抓到的数据要给别人
      · 日志 / 网络条目上都有「导出」或「复制」，导出后再发

六、反馈问题时请附上
  - 设备型号 + 系统版本
  - 被测包版本号
  - 应用版本：页面右上角关于里可以看到
  - 出问题时的截图（页面 + 手机界面）
